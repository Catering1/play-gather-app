# Game Matcher

Cria o design/frontend visual de uma plataforma chamada [NOME] para encontrar e organizar jogos desportivos.



Inspiração funcional: Footballers.pt e PrimePlay, mas não copiar o design.



Quero um design moderno, premium, jovem, minimalista e mobile-first, semelhante à qualidade visual de uma startup moderna. Fundo claro, tipografia forte, cards arredondados e uma cor de destaque energética (verde).



Páginas



Home



- Hero: “Encontra o teu próximo jogo.”

- Pesquisa por desporto, localização e data

- Jogos recomendados

- Modalidades: Futebol, Ping Pong, Ténis, Basquetebol, Badminton e Voleibol

- Secção “Como funciona”



Explorar



- Lista de jogos em cards

- Filtros por desporto, data, localização, nível e preço



Detalhe do jogo



- Foto

- Desporto, data, hora e localização

- Jogadores inscritos

- Preço

- Organizador

- Botão “Juntar-me”



Criar jogo



- Formulário simples com desporto, data, hora, local, jogadores, nível e preço



Perfil



- Avatar

- Estatísticas

- Próximos jogos

- Histórico



Usa dados fictícios/mockados.



Não implementar backend, Supabase, autenticação, pagamentos ou APIs.



Foca-te exclusivamente em UI/UX, design, responsividade e navegação entre páginas.



Quero uma interface que pareça um produto real e que depois possa ser desenvolvida com Claude Code.
